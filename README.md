# NEDO Challenge, Satellite Data 応募プロジェクト

経済産業省・NEDO「衛星データを活用したソリューション開発／NEDO Challenge, Satellite Data -衛星データで革新する未来の都市インフラ-」への応募一式。株式会社グリッド（GRID）。

**応募締切: 2026-08-31（月）正午 / 事務局への質問期限: 2026-08-24（月）正午**

作業の詳しい進め方と現在地は [CLAUDE.md](./CLAUDE.md) を参照。

## ディレクトリ

先頭の番号は区分を表す。十の位が区分、一の位がその中の順序。

| ディレクトリ | 内容 |
|---|---|
| [00_partners/](./00_partners/) | **相手先ごとの経緯**（本田技研工業・日本気象協会・大成建設・JTOWER）。フェーズ横断で、交渉の現在ステータスと時系列を追う |
| [10_matching/](./10_matching/) | **マッチングプログラム**への応募作業。参加者情報、回答案（改訂6世代）、企画書、生成スクリプト |
| [20_theme1_保温劣化監視/](./20_theme1_保温劣化監視/) | **テーマ1**（インフラマネジメント及び都市活動）。高分解能熱赤外衛星による都市エネルギーインフラの保温システム劣化監視。検討経緯・提案書・レビュー・PoC。**提出物は確定済み** |
| [30_theme2_ライフライン復旧/](./30_theme2_ライフライン復旧/) | **テーマ2**（インフラに係る防災・災害対応）。発災後のライフライン稼働・復旧マップ。**検討中** |
| [40_scripts/](./40_scripts/) | 両テーマ共通のスクリプト。参考資料の取得（`fetch_*.py`）、字数計測（`count_chars.py`）、PoC数値の追跡監査（`audit_poc_numbers.py`） |
| [50_koubo/](./50_koubo/) | 公募の一次情報。応募要項、応募説明会資料、応募申請書の様式 |
| [60_shiryo/](./60_shiryo/) | 社内向け説明資料 |

1応募者による複数テーマへの応募は可能（各テーマ1件まで）。様式1〜3（応募者情報）は2テーマ共通、様式4（提案書）だけがテーマごとに別物になる。

## 全体の流れ

```
10_matching        20_theme1 / 30_theme2
マッチング応募  →  提案書執筆・PoC  →  8/31 応募
      │
      └─→ 00_partners（相手先との関係は以降も継続）
```

**応募は単独で進めるのが本線**であり、マッチングプログラムは今後の企業対企業の接点をつくる場として活用する方針。詳細は [00_partners/README.md](./00_partners/README.md) を参照。
