## 物差し1: 衛星の使い道の4類型（B1・B4の打ち消し。**最重要**）

**生成する候補は、この4類型に振り分けて数を管理すること。**

| 類型 | 中身 | 生き残りやすさ |
|---|---|---|
| **見る**（監視・検知） | 変化・異常・存在を見つける | **最も弱い。** 届出制度で答えが届く／顧客が内製している／ドローンが高分解能で座っている |
| **測る**（定量化して基準にする） | 数値を出し、それが**計画値・設計値・契約値**になる | **強い。** テーマ1（劣化の定量化）がここ |
| **遡る**（過去を復元する） | 現在の観測では決まらない**過去の状態**を出す | 強いが**条件付き**（下記）。テーマ2（40年アーカイブ）がここ |
| **証明する**（第三者に対する証拠） | 利害の対立する二者の間で、**中立の第三者が出したという事実**に価値がある | 未開拓。**ただし受益者と支払者が逆を向きやすい**（G8） |

**生成の割当は「見る」1／「測る」3／「遡る」3／「証明する」3 を目安にすること。**
**「見る」の案を4件以上出したら、それはバイアスが再発している。**

### 3体の掃引（計52件・生存0件）で判明した、各類型の限定条件

**「遡る」には時間スケールの限定がある。** 遡及できるのは**無償・長期・全球一様のアーカイブだけ**で、
高分解能・高頻度センサはすべてタスキングなので**争点が起きてからしか撮れない**。したがって空間分解能は
**Landsat 30m／TIR 100m（44年）・Sentinel-2 10m（11年）・Sentinel-1 20m（12年）**に固定される。
**年〜十年スケールの量にしか使えない**——日〜週の事実確定（操業再開日・直近3年の稼働率）は
実効再訪22.9日に負けて全滅した。

**「測る」には制度側の限定がある。** **設計値・基準値は、制度が「値そのもの」を配布している**
（垂直積雪量・基準風速・流出係数・舗装の温度区分）。実測値に法的地位が無く、しかも実測すると設計が重くなるので、
**買い手には測らない側にインセンティブがある。**「設計値を実測で置き換える」形にした瞬間にG1で死ぬ。

> **「測る」型の生存帯は1本しかない——制度が「求めよ」とだけ言い、「値」を与えていない量。**
> 制度が値を与えていればG1で死に、制度が求めてすらいなければ買う動機が無くG8で死ぬ。その間の細い帯だけである。

**そして最も重要な構造（3体が独立に到達した）:**

> **制度が届かない争点は画素に入らず、画素に入る争点は制度が届いている。**

戸建て屋根10m角はLandsat 30mで**0.11画素**、キュービクル5m角で0.03画素、冷却塔20m角で0.44画素。
余裕が出るのは湛水域300m角（100画素）・流域1km角（1,111画素）からで、**その大きさの争点は日本では
ほぼ例外なく制度が計測・公表している**（ダムの貯水位・放流量、堤防の縦横断測量、堆砂測量）。
**現行2案はこの二律背反の抜け穴にいる**——テーマ2は流域スケールで画素が足り、かつ火口に観測点が1つも無い。

**物差し3は物差し1と独立ではない。** 買い手の入れ替えが効くのは**「証明する」でだけ**である。
「測る」では、量が制度から届くかどうかは**量の性質で決まり、買い手を替えても動かない**
（保険・金融・訴訟・報道へ7件振ってG1の壁は1件も動かなかった）。

## 物差し3: 買い手の類型（B2の打ち消し）

**課題から入る前に、買い手を先に選ぶこと。** 過去の掃引は上2つにほぼ偏っていた。

| 買い手 | 買う理由 | 過去の掃引での出現 |
|---|---|---|
| インフラの管理者 | 保全・保安 | **過多**（ほぼ全件） |
| 規制する官庁・自治体 | 法定業務の履行 | **過多**（そして所管官庁の内製で死ぬ） |
| **保険・再保険** | 引受・料率・支払査定 | 薄い |
| **金融（レンダー・ファンド）** | 融資先の期中モニタリング、DD | 薄い |
| **投資家・格付** | 開示情報の検証 | ゼロ |
| **訴訟・紛争の当事者** | 過去の事実の立証 | ゼロ |
| **上流の供給者** | 顧客設備の状態把握 | ゼロ |
| **報道・NGO・研究** | 検証可能性 | ゼロ |
| **海外の同種顧客** | 日本で作った手法の移植 | ゼロ |

**「見る側と見られる側が違う」構図では、ドローンも立入も原理的に使えない。** 衛星だけが許可を要さない。
**これは好みではなく構造的な排他性で、堀としても効く。**（ただしG2(b)は依然として当てること）

### 排他性には時間の条件がある（第9巡の発見。**この条件を先に当てること**）

> **排他性が価値になるのは「相手方に受忍義務が発生しない争点」だけである。**

**請求・提訴・保証請求は、いずれもその瞬間に相手方へ協力義務を発生させる**——損害調査への協力、検証・鑑定、文書提出命令。
**その瞬間に鑑定人もドローンも立入可能になり、衛星の排他性は消滅する。** しかも**金が動くのはまさにその瞬間**である。

大屋根の風災査定（被災前の屋根状態の遡及提示）は G1〜G7 を通り物理も **SNR 7.8** で通ったのに、ここで死んだ。
**保険・訴訟・保証を買い手にする「証明する」型は、ほぼ全部この刃を受ける。**

**現行テーマ2が構造的にこれを外れているのは、相手方が自然（火口の積雪）で、受忍義務を負う主体が存在しないからである。**

### 「証明する」型のもう1つの構造（第9巡）

**自己申告値が制度に届いているということは、その測定を誰かが既に受注しているということである**（申告値は空から降ってこない）。
**G1を外した分だけ G2(c)(d) に当たりやすくなる。** 逃げ道は1つ——**申告が「標本」（年数回・選んだ条件）で、争点が「面的・連続的」な場合**。

そして**生成の前に判別できる**: 制度が届ける値が **(i) 利害関係者の自己申告** か **(ii) 独立の公的測定** か。
**(ii) なら組み替えは効かない**（水準測量・海保の油監視・受入証明書・引取実績はすべて(ii)で、組み替えは1件も効かなかった）。
