# 参考資料アーカイブの台帳

提案の根拠として取得した一次資料（官公庁PDF・HTML・統計等）の所在と同一性を記録する台帳。

## なぜこれがあるか

これらの資料は当初、取得系統ごとに専用のgitブランチへコミットされていた。当時の作業環境
（クラウドサンドボックス）が対象ホストへの egress を遮断されており、GitHub Actions ランナーで
取得して結果をブランチに置くしか手段が無かったためである。

その結果、**リポジトリの履歴が 2.6GB に膨れ、clone に30分以上かかる**状態になった。本線（HEAD）
から到達できるのは約20MBで、残りはすべてサイドブランチ上の収集データだった。

2026-08-11 にローカル環境から対象ホストすべてへ到達できることを確認したため、この方式は不要に
なった。そこで**原本をBoxへ退避し、gitにはこの台帳だけを残す**構成に改めた。

Webの資料は消える（リンク切れが起きる）ため、原本そのものを保全している。台帳だけでは
不十分という判断である。

## 出典を辿る手順

1. 文書中の記述（例:「`origin/policy-refs` の `g_ddg_0__PDF_土木設計業務等委託契約書_案.txt`」）
   から、取得系統の名前（`policy-refs`）を読む
2. 本台帳で該当行を引き、Boxの `policy-refs.zip` を開く
3. zip内の同名ファイルが原本である
4. 同一性を確かめるときは `archive_manifest.tsv` の `sha256` とzipのハッシュを照合する

`git show origin/<branch>:<path>` は、ブランチを削除するまでの間は引き続き使える。

## 同一性の検証

`archive_manifest.tsv` に各zipの SHA-256 を記録している。改変や取り違えを疑うときは照合する。

```bash
shasum -a 256 policy-refs.zip
```
