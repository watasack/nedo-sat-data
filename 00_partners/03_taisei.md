## 2026-08-05 時点の事業化・マネタイズ検討

以下は辞退連絡前の検討であり、**現時点で実行予定はない**。テーマ2（災害後の建物・インフラ状況把握）の分析として参照する場合に限り有効。

### 1. 相手の希望

大成の参加者は、震災時の建物状況判定、建物の構造ヘルスモニタリングを専門としている。衛星データ活用経験はほとんどなく、建築・土木知識と衛星データ技術を結び付けたい意向である。

希望は、災害後の建物・インフラ構造物の状況を迅速に把握することであり、関心テーマはテーマ2である。

重要な制約として、顧客の観測データは提供できず、設置場所も特定できないと明記されている。

### 2. 推奨テーマ

#### 災害後の建物・インフラ緊急点検・応急対応計画最適化

1. SAR・光学衛星等から、地盤変状、建物群の変化、浸水・土砂等を広域把握する。
2. 大成の構造ヘルスモニタリング知見に基づき、建物・構造物の要確認度を評価する。
3. GRIDが、人命、施設重要度、周辺被害、アクセス性等を考慮して緊急点検順位を決定する。
4. 点検班、ドローン、応急補強資材、重機等の配置・巡回・投入順序を最適化する。

衛星で建物の安全性を確定するのではなく、詳細点検が必要な施設群を絞り込み、限られた専門家をどこへ送るかを支援する。

### 3. 顧客と支払者

| 区分 | 想定主体 | 支払う理由 |
|---|---|---|
| 利用者 | 大成の災害対策・施設管理・構造技術担当 | 災害初動と点検班配置を迅速化する |
| 主な支払者 | 建物所有者、デベロッパー、自治体、施設管理者 | BCP強化、休業時間短縮、安全確認迅速化 |
| 販売・実行主体 | 大成 | 構造診断、点検、応急対応サービスを高度化する |
| 技術提供者 | 衛星解析事業者、GRID | 広域把握と行動計画を提供する |

### 4. マネタイズポイント

災害は発生頻度が低く、発災時だけ課金するモデルでは安定収益にならない。そのため「平時の年間待機契約＋発災時の追加課金」を基本とする。

| 売上項目 | 課金方法 | 収益の帰属イメージ |
|---|---|---|
| BCP・初期設定 | 建物ポートフォリオごとの導入費 | 大成＋GRID |
| 年間待機・監視契約 | 建物数、拠点数、対象地域ごとの年額 | 大成＋GRIDの継続収益 |
| 災害時アクティベーション | 災害イベント、対象地域、解析回数 | 大成＋衛星解析事業者＋GRID |
| 緊急点検計画モジュール | 年間ライセンスまたは建物数課金 | GRIDの主な継続粗利 |
| 現地点検・構造診断 | 点検件数、技術者工数 | 大成 |
| 応急補強・復旧設計 | 個別工事・設計契約 | 大成 |

#### GRIDが利益を得る中心

- 建物ポートフォリオごとの年間最適化ライセンス
- 災害前に作成する点検班配置、代替拠点、応急対応シナリオの初期モデル構築費
- 災害時に新しい観測情報を反映するリプラン機能の利用料
- 大成のBCP・構造モニタリングサービスへ組み込むOEMライセンス

災害後の一時的な緊急対応売上だけでなく、平時の訓練、BCP更新、設備台帳更新でも使用する設計にする。

### 5. 顧客の経済価値

- 安全確認が終わるまでの建物閉鎖・操業停止時間を短縮できる。
- 構造専門家を高リスク施設へ優先投入できる。
- 災害直後の過剰点検と見逃しの双方を減らせる。
- 建物所有者は、BCPの実行可能性を平時から説明できる。

価格は、点検工数削減だけではなく、休業・操業停止の期待損失削減に基づいて設定する。病院、物流施設、工場、データセンター等、停止損失が大きい施設ほど支払意思が高いと考えられる。

### 6. データ制約を踏まえたPoC

1. 公開されている過去災害・建物被害データを使用する。
2. 大成からは顧客名・住所・観測値を出さず、匿名化した状態区分や模擬データで業務ロジックを検証する。
3. 可能であれば研究所、公開可能な実験施設、自治体施設を実証対象とする。
4. GRIDの処理を大成指定環境内で実行する構成も検討する。
5. 技術精度だけでなく、緊急点検計画作成時間と点検完了時間の短縮を評価する。

### 7. 採算上のリスク

- 顧客データと場所を利用できないため、初期PoCの実務性が低くなる可能性がある。
- 災害発生時だけの従量課金では売上が不安定になる。
- 大成の個別建設案件ごとのカスタマイズが増えると、製品化しにくい。
- 安全判定に関する責任が重いため、最終診断ではなく点検優先順位支援として責任分界を明確にする必要がある。

### 8. 初回面談で確認すること

- 大成の正式な部署・対象顧客・既存サービスとの関係
- 匿名化・集約化した状態ラベルであれば利用可能か
- 研究所や公開可能な施設を実証に使えるか
- 大成社内利用を目指すのか、建物所有者向け共同サービスを目指すのか
- 年間BCP契約へ組み込む余地と、契約主体・売上配分
- 発災時のシステム利用責任と最終判断者

### 9. 現時点の判断

社会的意義は大きいが、データ制約と低頻度イベントという収益上の弱点がある。年間待機契約、平時訓練、BCP更新を商品に含め、GRIDのライセンスを毎年発生させられる場合に事業性が成立する。
