## 2026-08-05 時点の事業化・マネタイズ検討

以下は候補が4社あった時点の検討であり、**優先度の記述は現状と一致しない**。テーマ・収益構造・確認事項の分析内容は引き続き有効。

### 1. 相手の希望

日本気象協会は、気象観測、数値予報、衛星、環境調査等のデータを用いた観測・解析・予測・評価に強みを持つ。GOSATデータの検証支援、ひまわり8・9号を使った日射量推定・サービス運用の実績がある。

希望しているのは、衛星の広域性・継続性・均質性と、地上観測・気象予測を組み合わせ、インフラの状態把握、災害リスクの早期検知、点検・予防保全を高度化することである。関心テーマはテーマ1である。

### 2. 検討テーマ（現時点では低優先）

#### 衛星・気象データによるインフラ予防保全計画の最適化

1. 衛星データから、地盤、斜面、植生、土地被覆、構造物周辺環境の変化を抽出する。
2. 日本気象協会が、降雨、気温、風、積雪等の履歴・予測から、劣化・災害の外力を評価する。
3. 現地観測・環境調査により、衛星・気象解析を検証する。
4. GRIDが、施設別リスクを点検、保守、補修、要員配置、予算配分へ変換する。

対象候補は道路・法面、ダム、発電所、送配電設備である。最初のPoCでは一分野に限定する。

ただし、事業化・実証にはアセットオーナーが保有する設備台帳、点検・補修履歴、予算・人員制約、実証フィールドが不可欠である。日本気象協会とGRIDを中心とするNEDO Challengeのマッチング枠内だけではこれらを確保しにくいため、本テーマの優先度は下げる。

### 3. 顧客と支払者

| 区分 | 想定主体 | 支払う理由 |
|---|---|---|
| 利用者 | 道路、電力、ダム等の保守・防災担当 | 点検・保守の判断に使う |
| 主な支払者 | アセットオーナー、自治体 | 稼働率向上、点検費削減、事故・停止損失回避 |
| 共同販売者 | 日本気象協会 | 既存顧客へ気象情報の上位サービスとして提供 |
| 技術提供者 | 衛星解析事業者、GRID | 状態・外力・意思決定を接続する |

日本気象協会とGRIDの2社だけでは実証データと支払者が不足するため、アセットオーナーを含む3社以上の構成を前提とする。

### 4. マネタイズポイント

#### 継続する場合の収益構造（仮説）

| 売上項目 | 課金方法 | 収益の帰属イメージ |
|---|---|---|
| 初期リスクモデル構築 | 対象設備・地域別の初期費 | 日本気象協会＋GRID＋衛星解析事業者 |
| 気象データ・予測API | 地点数、面積、更新頻度、API量 | 日本気象協会 |
| 現地観測・検証 | 調査地点、期間、観測内容 | 日本気象協会 |
| 衛星解析 | 面積、時系列数、更新頻度 | 衛星解析事業者 |
| 保全最適化SaaS | 施設数、管理延長、年間利用 | GRIDの主な継続粗利 |
| 高頻度アラート・SLA | 更新間隔、通知先、可用性保証 | 日本気象協会＋GRID |
| 年度保全計画支援 | 年次報告・計画更新 | 日本気象協会＋GRID |

#### GRIDが利益を得る中心

- 気象・衛星リスクを点検・補修計画に変換するエンジンの年間ライセンス
- 施設台帳、点検履歴、予算・人員制約を組み込む初期導入費
- 複数気象シナリオに対する頑健計画・シナリオ比較の上位機能
- 日本気象協会の顧客基盤を通じた横展開時のライセンス収入

継続条件を満たす場合は、日本気象協会が元請・販売窓口となり、GRIDの最適化機能をOEMまたは共同サービスとして組み込むモデルが候補となる。この場合、案件ごとの受託費ではなく、顧客数・施設数に応じた最低保証＋従量ロイヤルティを設定する。

### 5. 顧客の経済価値

- 天候に関係なく定期点検する方式から、気象外力と状態変化に応じた点検へ移行できる。
- 降雨後、強風後、凍結融解後等の臨時点検対象を絞り込める。
- 設備停止や災害につながる兆候を早期に検知できる。
- 予算制約下で、リスク低減効果が高い補修を選択できる。

価格の根拠は、点検回数削減だけではなく、停止時間、事故、緊急補修等の期待損失削減まで含める。

### 6. 継続する場合のPoCから商用化まで

以下は、後述する継続条件を満たした場合の進め方である。

1. 日本気象協会の既存顧客等から、道路・電力・ダム等の実証先を1社選定する。
2. 過去の気象、衛星、点検・故障履歴を用いてリスクスコアを構築する。
3. 上位リスク施設への点検集中による捕捉率と点検削減率を評価する。
4. 翌年度の点検・補修計画作成に適用する。
5. 日本気象協会の既存サービスへ追加モジュールとして組み込み、同業顧客へ販売する。

### 7. 採算上のリスク

- 対象インフラを広げ過ぎると、設備ごとの劣化モデルが個別開発になる。
- 日本気象協会の既存コンサルティング案件の付帯機能に留まると、GRIDの継続収益が小さくなる。
- 気象と故障・劣化の因果関係を説明できない場合、顧客が予算判断に使えない。
- アセットオーナー不在の技術実証では、商用価格の検証ができない。
- 設備台帳、点検・補修履歴、予算・人員制約を利用できない場合、保全優先順位の有効性を検証できない。

- 気象リスク・災害時の広域状況把握について、顧客データへの依存が少なく、公開データと日本気象協会が提供可能な資産で初期検証できる課題があるか

### 9. 現時点の判断

本テーマは現時点では低優先とする。継続検討の条件は、(1) 日本気象協会が提供可能な、案件の差別化に直結する独自の観測・予測・評価資産を具体化できること、または (2) 必要なデータと実証フィールドを提供するアセットオーナーが早期に参画することである。いずれも満たさない場合は、マッチング枠内での事業化・実証を進めない。

衛星データは日照・発電量予測を新規開発する目的では用いない。必要な場合に限り、気象リスク評価や災害時の広域状況把握の入力として位置付ける。

再エネ・蓄電池運用最適化も代替案として検討したが、日照・発電量予測は既存提供者が多く、公開データだけで初期検証する場合、日本気象協会と組む必然性を示しにくい。また、複数事業者の蓄電池を束ねた市場取引・制御は、既存アグリゲーターとの契約、取引権限、顧客間の情報遮断、利益相反、市場の公正性に関わるため対象外とする。関連テーマを扱う場合も、日本気象協会とGRIDは取引実行を代行せず、顧客ごとに分離された意思決定支援に留める。

代替案を検討する場合は、顧客の設備・取引データや市場実行への依存が少ない、気象リスクのスクリーニング、災害時の広域状況把握、公開データを用いた事前評価等を候補とする。ただし、日本気象協会が提供できる独自資産とその優位性は次回面談で確認し、確認前に前提としない。
