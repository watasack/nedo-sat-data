# 相手先ごとの経緯

NEDO Challenge, Satellite Data のマッチングプログラムで接触した候補先について、フェーズをまたいで交渉経緯を追うためのディレクトリ。

フェーズ1（マッチング応募）で終わる話ではなく、提案書執筆・PoC が進んでも相手先との関係は続くため、**フェーズ別ディレクトリではなくここに集約する**。各ファイルは冒頭に現在ステータス、その下に時系列ログを積む形式とし、状況が動いたら追記する。

## 前提: マッチングの位置づけ

**コンテストへの応募は単独で進めるのが本線**であり、マッチングプログラムは**今後の企業対企業の接点をつくる場**として活用する方針である（2026-08-07 社内相談で確認）。

したがって本ディレクトリの記録は、共同応募に向けた進行管理ではなく、**将来の商談につながる関係と、そこで得た相手先の課題認識を残すこと**を目的とする。`../20_theme1_保温劣化監視/` 以降の提案書執筆が相手先に依存せず進んでいるのは、この方針によるもので齟齬ではない。

参加の第一目的は衛星データ×数理最適化での実績づくり。会社としては受賞を前提としない自己啓発的な位置づけで、本業の傍ら無理のない範囲で進めるものとして整理されている。
