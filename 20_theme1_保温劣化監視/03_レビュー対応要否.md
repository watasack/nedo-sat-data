## 0. 公式要項から確定した前提（仕分けの物差し）

| # | 確定事実 | 仕分けへの含意 |
|---|---|---|
| F1 | 1次審査基準は4つのみ: ①課題の妥当性と解決への貢献度 ②衛星データ活用の有効性（技術実現可能性） ③サービスの新規性 ④実用化による社会発展性 | 投資家級の事業計画・完全な技術実証は1次では要求されない |
| F2 | **「世界初」の要求はない**。「既存システムの機能性向上・組み合わせも対象」と明記 | 世界初は加点主張であって要件ではない。反証リスクに見合う範囲に限定してよい |
| F3 | 1次審査の提出物は「**構想文章で構いません**」 | 応募時点で必要なのは「確認済みの根拠+誠実なリスク認識+検証計画」。実測データは必須でない（あれば強い） |
| F4 | 2次審査は「**プロトタイプ以上のシステム開発**」が必須。未達なら1次通過でも2次に進めない | 開発期間内の目標は統計的実証でなくプロトタイプ+実データでの動作証拠 |
| F5 | テーマ1の対象例示に「道路や橋梁、河川、上水道、**電力・ガス**」と明記 | エネルギーインフラは正面から対象。コンビナート・製油所のみ残グレー |
| F6 | 有償データは「要望に応じ購入検討」だが「**提供の確約はできません**」と明記 | HotSat-2調達費の自己負担計画は必須記載事項 |
| F7 | スケジュール: 応募締切8/31正午、**質問受付期限8/24正午**、1次結果10月下旬、開発10月下旬〜2027年5月下旬（約7カ月）、2次審査2027年7月 | 照会は実質あと2週間。開発期間7カ月はレビューの前提通り |
| F8 | 過去回テーマ（Green Earth: エネルギーマネジメント基盤構築等）が**主たる目的の提案は対象外** | 省エネ・GXを前面に出しすぎると重複判定リスク。主目的は「インフラ劣化の点検・監視」に固定する |
| F9 | 衛星調査より: SatVuは建物向け熱損失指標（ESA資金、2025）を訴求済み。Fortum/Advianが**衛星による**地域熱供給導管の漏水検知を実証済み（2020）。HotSat-2はNEdT非公開（公表は感度「<2K」のみ）、分解能3.5mは直下値（オフナディア最大6.8m）、現行1機で再訪1〜2日、3.5m級MWIRの代替衛星は現存せず | 「先行事例なし」は限定なしでは虚偽になる。数値前提の表現修正が必要 |

## 1. 審査員レビュー（review_審査員.md）の仕分け

| 指摘 | 元の重大度 | 検証結果 | 対応 |
|---|---|---|---|
| 6. テーマ適合性未照会 | 致命的 | **降格（中）**。F5により発電所・地域熱供給・上下水処理場は「電力・ガス、上水道」の例示範囲で正面から読める。コンビナートのみグレー | **要対応**: 照会文案（04）を8/24までに送付。骨子に要項の例示を引用（v0.2反映済み） |
| 7. 月次トレンドが期間内に実証不可能 | 致命的 | **半分正しい**。7カ月・アーカイブ不在は事実。ただしF4より2次の要求は「プロトタイプ以上」であり完全実証ではない | **要対応（構成変更）**: 検証を横断判別型（AUC）+ステップ検知に組み替え、トレンドは「フィージビリティ確認」に格下げ（v0.2反映済み） |
| 5. 制約自白が「弱さの自白」化 | 重大 | 正しい。ただしF3より応募時点はS/N一桁概算+設計原則の提示で足りる | **要対応**: 課題の主役を「保温システムの劣化」そのものに再定義し、CUIは下流発見便益に再配置（v0.2反映済み）。S/N概算はPhase 0タスク |
| 1. 世界初が悪魔の証明 | 重大 | **要件上は不要（F2）**。ただし新規性③の審査там説得力に影響 | **要対応（低コスト）**: 主張を「保温システム劣化の保全業務への適用として先行なし」に限定し、調査範囲を開示（v0.2反映済み） |
| 2. SatVu自身の熱損失ユースケースと衝突 | 重大 | **事実と確認（F9）**。ESA資金のHeat Loss Index（建物向け）が実在 | **要対応**: 近傍先行事例を自ら列挙し差分を明記（v0.2反映済み） |

## 2. 技術レビュー（review_技術.md）の仕分け

審査基準②「技術実現可能性」に直結するため**免除される指摘はない**。ただしF3より、応募時点では「解けている」必要はなく「認識し検証計画に織り込んでいる」ことを示せばよい。

| 指摘 | 元の重大度 | 対応 |
|---|---|---|
| T-1 低放射率・天空反射（ε問題） | 致命的 | **要対応（設計転換）**: 絶対温度→シーン内相対比較・兄弟資産差分へ。v0.2の2.2節を全面改稿。ε実測をPhase 1に追加 |
| T-2 トレンド検知に年単位必要 | 致命的 | **要対応**: ステップ変化検知（月次）と漸進トレンド（年次）に分割して約束を書き分け（v0.2反映済み） |
| T-3 降雨後回復特徴量が成立しない | 致命的 | **要対応（降格）**: 「新規性の核」→機会的補助特徴量へ。成立確率の自前計算をPhase 0に。季節湿潤指標を代替に採用（v0.2反映済み） |
| T-4 検知率・誤報率が期間内に出ない | 致命的 | **要対応**: 横断判別型（AUC）+地上同時観測に再設計。リードタイムはKPIから外し事例報告に（v0.2反映済み） |
| T-5 垂直面不可視 | 重大 | **要対応**: 可視面カバレッジ率を製品仕様化、視線角固定タスキング（v0.2反映済み） |
| T-6 操業交絡の識別可能性 | 重大 | **要対応**: 最小データ要件の明記+兄弟資産差分を設計の柱に昇格（v0.2反映済み） |
| T-7 ε経年変化の偽トレンド | 重大 | **要対応**: 外装更新履歴連携+LWIR併用ロードマップ（v0.2反映済み） |
| T-8 位置合わせ誤差 | 重大 | **要対応**: サブピクセル位置合わせ+境界エロージョンを前処理仕様に（v0.2反映済み） |
| T-9 地域熱供給は物理が別物 | 重大 | **要対応**: 審査員3と同じ処置。舗装越しΔTのフィージビリティは対象から外すか独立検証に（v0.2では筆頭から降ろした） |
| T-10 昼夜ペアの矛盾 | 重大 | **要対応（削除）**: Phase 1から昼夜ペアを削除、夜間主体の根拠を一文明記（v0.2反映済み） |
| T-11 気象正規化の分解能不足 | 中 | **要対応**: 現地簡易気象計をPhase 2に追加（低コスト・審査映え） |
| T-12 プルーム汚染 | 中 | **要対応**: 資産マスク+ロバスト統計（v0.2反映済み） |
| T-13 CO2換算の誤差伝播 | 中 | **要対応**: 相対値表現+誤差幅併記（v0.2反映済み） |
| T-14 「面的進行」の根拠不足 | 軽微 | **要対応**: 面的熱性能劣化とCUIホットスポットの書き分け（v0.2反映済み） |

## 3. 事業性レビュー（review_事業性.md）の仕分け

F1④は「実用化スケジュール・想定ユーザー・市場ニーズ・社会的インパクト」であり、投資判断ではない。よって**方向は採用、粒度は要約**が基本。

| 指摘 | 元の重大度 | 対応 |
|---|---|---|
| A-1 「点検予算は既存」は誤り | 致命的 | **要対応**: 新規費目と認め、スーパー認定（定修延伸）を稟議根拠の筆頭に（v0.2反映済み） |
| B-2 ドローン定期便に負ける | 致命的 | **要対応**: 衛星の勝利条件3つ（多拠点横並び・地区相乗り・第三者資産）+ドローン事業者のチャネル化（v0.2反映済み） |
| B-1 教師データは堀でない | 重大 | **要対応**: 堀を（1）地区相乗りの原価優位（2）規制文脈の実績（3）契約設計されたベースラインモデル、に差し替え（v0.2反映済み） |
| A-3 タスキング原価で赤字 | 重大 | **要対応**: 相乗りモデル（損益分岐3〜4社/シーン）を原価構造に明記（v0.2反映済み）。実勢価格確認はPhase 1 |
| A-2 二枚目の財布は薄い | 重大 | **要対応**: 「独立の財布」→「一枚目の稟議の補強材料」に降格（v0.2反映済み）。**F8の重複回避とも整合**（GXを主目的にしない） |
| C-1 操業データのリードタイム | 中 | **要対応**: 縮退検証の並走を明記（v0.2反映済み） |
| C-2 地域熱供給は収益柱にならない | 中 | **要対応**: フレーミング・公共実績目的と内部整理（v0.2反映済み） |
| B-3 スイッチングコスト欠如 | 中 | **要対応（一部）**: ベースラインモデルの契約設計のみ採用。ネットワーク効果は主張しない |
| C-3 海外展開の飛躍 | 中 | **要対応（縮小）**: 乾季市場選定の一行に縮小（v0.2反映済み） |
| D-1 賞金後の見通し | 中 | **要対応（一文）**: NEDO他事業・共同開発契約への接続を一文（v0.2反映済み）。詳細は2次までの宿題 |
| A-4 市場ニッチの未開示 | 軽微〜中 | **要対応**: TAM20〜40億円+隣接展開を正直に記載（v0.2反映済み） |

## 4. レビューが見落としていた追加リスク（今回の検証で新規発見）

1. **Green Earth重複判定リスク（F8）**: 過去回テーマ「エネルギーマネジメント基盤構築」が主目的と判定されると対象外。→ v0.2では主目的を「インフラ構造物（保温システム）の劣化の点検・監視」に固定し、省エネ・CO2は副次便益として記載。照会文案（04）にも確認質問を入れた。
2. **分解能の表記精度（F9）**: 3.5mは直下値でオフナディア最大6.8m。「3.5m級（直下）」と正確に書かないと専門審査員に突かれる。→ v0.2反映済み。
3. **NEdT非公開（F9）**: 公表は感度「<2K」のみ。「NEdT確認」はPhase 0/1の最重要タスクとして残る（JSI経由での確認は変わらず必要）。
