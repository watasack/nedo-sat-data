# 提案書骨子: 衛星熱赤外による都市エネルギーインフラ保温システムの広域劣化監視

NEDO Challenge, Satellite Data「衛星データで革新する未来の都市インフラ」応募用（テーマ1: インフラマネジメント及び都市活動における課題解決）
バージョン: 骨子 v0.2（2026年8月8日）

## v0.1からの主な変更点

1. 課題の主役を「CUIスポット検知」から「**保温システムという見えないインフラの劣化監視**」に再定義（CUIは点検派遣先での二次的発見便益に再配置）。エネルギー・CO2は副次便益に固定（過去回テーマとの重複回避）

6. 事業化パスを全面改稿（新規費目と認めた稟議設計、地区相乗りの原価構造、ドローンとの分業）
7. チーム体制節・公募審査基準との対応マップを新設

## 1. 背景・課題

### 1.1 対象インフラ: 「保温システム」という見えないインフラ
都市の機能は、発電所・清掃工場（廃棄物発電）・地域熱供給プラント・上下水処理場等のエネルギー供給インフラに支えられている（本公募要項はテーマ1の対象例として「電力・ガス」「上水道」を明示）。これらの設備の中核は保温材（断熱材+外装板)で覆われた高温の塔槽・タンク・配管・ダクト群であり、その保温システムは総面積が一事業所で数万〜数十万m²に達する巨大な構造物でありながら、**外から状態が見えないまま経年で必ず劣化する**。

### 1.2 保温システム劣化がもたらす二重の損失
1. **安全**: 保温材内部への水分浸入は保温材下腐食（CUI）を引き起こす。CUIは外部から見えないまま進行し、配管保全コストの40〜60%を占めるとする研究がある【出典を最終稿で付す: NACE/AMPP系文献】。見逃せばプロセス停止、漏洩・火災等の重大事故に至る
2. **エネルギー・CO2**: 劣化した保温は恒常的な熱損失=燃料浪費=CO2排出（劣化保温100m²で年200〜300万円規模のエネルギー損失に相当し得る）

なお本提案の主たる目的は1・2の源である**保温システムの劣化そのものの点検・監視**（テーマ1「インフラ構造物の劣化等の点検や監視」）であり、エネルギー・CO2の定量化は劣化検知の副次的便益である。

### 1.3 劣化の2つの様態（本提案の検知設計の前提）
- **面的劣化**: 保温材の経年沈下・圧密・広域浸水による、ユニット規模での熱性能低下。面的ゆえ広域センシングと相性が良い
- **局所劣化（CUIホットスポット）**: 水の侵入点・低所滞留部・支持金具部で局所的に進行。近接センシング（手持ち・ドローン)の担当領域

### 1.4 現行点検手法の構造的限界
現行の保温点検は、手持ちサーモグラフィの徒歩サーベイ、足場を組んだ保温材剥離検査、放射線・超音波等のNDT、近年はドローン熱赤外である。いずれも性能は高いが「歩いた/飛んだ場所しか見えず、コストが対象距離・面積に比例する」ため、膨大な保温面積の網羅は経済的に不可能。実態は数年周期の抜き取り点検であり、点検の狭間・対象外設備で劣化が静かに進行する。点検人材の高齢化・担い手不足が周期の維持自体を脅かしている。

**課題の本質は「見る技術の不足」ではなく「見る範囲と頻度の不足」である。**

## 2. 提案システム

### 2.1 コンセプト
2026年6月29日に商用運用が始まった高分解能熱赤外衛星（英SatVu HotSat-2: MWIR帯、分解能3.5m（直下、オフナディア時最大6.8m）、公表感度<2K、昼夜撮像可、現行1機で再訪1〜2日に1回、9機コンステレーション計画あり。日本スペースイメージングが2026年7月10日に国内販売開始）を用い、**「全設備・定常・宇宙から」の保温システム劣化監視**を実現する。点検（スケジュールされた抜き取り検査）を監視（全数の定常スクリーニング）に転換し、地上点検はその下流工程（衛星が絞った区画の精密確認）に再配置する。

従来の衛星熱赤外（Landsat級の約100m）では設備単位の解析が物理的に不可能だった。3.5m級の商用供給は2026年6月に始まったばかりであり（先行機HotSat-1は2023年打上げ後に運用停止し、商用供給は不連続だった）、本提案はこの新観測資産の上に築く最初のインフラ保全アプリケーションを狙う。

### 2.2 測定設計の3原則（物理制約を正面から認めた設計）

**原則1: 温度の絶対値を測らない — シーン内相対比較を一次指標とする**
監視対象の外装板は金属（アルミジャケット等）で、MWIR帯の放射率εは0.1〜0.4と低く、放射率不確かさと天空放射の反射（晴天/曇天夜間で見かけ数K〜十数K変動）が、検知したい数℃の信号を上回る系統誤差を生む。よって本システムは温度の絶対値・撮像間の単純差分に依拠せず、(a) **同一撮像内の空間コントラスト**（同一資産上の局所異常。ε・天空条件が共通モードとして相殺）、(b) **兄弟資産差分**（同一ユニット内の並列系列・同種タンク間の相対比較。負荷・気象・εの経年も共通モード化）を一次指標とする。時系列比較は晴天夜間・類似視線角の撮像に層別し、シーン内不変参照面（舗装・水面）で相対校正した上でのみ行う。

**原則2: 検知の約束を時定数で分ける**
- **ステップ変化検知（月次の約束）**: 外装板の脱落・大規模浸水等の急性イベントは、集約指標の段差として少数観測で検出可能。月次レポートの主内容
- **漸進トレンド（年次の約束）**: 保温性能の緩やかな劣化トレンドは、季節1周期以上の蓄積を要する（統計的検出力の制約）。年次評価として提供し、9機コンステレーション化による高頻度化で短縮するロードマップを持つ

**原則3: 可視面カバレッジを事前開示する**
衛星が見えるのは屋根・天板・ラック最上段等の上向き面であり、タンク側板・塔槽胴部等の垂直面は原理的に監視対象外。資産ごとの可視面カバレッジ率を3Dモデル（PLATEAU・プラント3D）から事前計算し、製品仕様として顧客に開示する。垂直面・個別配管のCUIスポットは近接点検（ドローン・手持ち）の担当であり、本システムの出力は「今月、点検チームをどのユニット・どの資産に送るべきか」の優先順位リストと根拠マップである。

### 2.3 検知の2階層
- **階層1（直接検知）**: タンク屋根（径10〜80m）、大型塔槽天板、加熱炉・大口径ダクト、建屋屋根等の大型上向き面は、シーン内コントラストによる劣化スポット・異常パターンを直接検出
- **階層2（集約スクリーニング）**: 配管ラック・プロセスユニットは、ユニット単位の放熱指標（中央値・トリム平均等の外れ値耐性統計。フレア・蒸気プルーム等の既知過渡熱源はマスク除外）を兄弟資産差分・ステップ検知にかけ、「異常が出ているユニット」を特定。多重比較はFDR制御で誤報率を管理

### 2.4 データ構成（各データに因果的役割を1つ）
| データ | 役割 | 具体 |
|---|---|---|
| 高分解能熱赤外 | 検知（主信号） | HotSat-2等。夜間撮像主体（金属面の太陽反射・サングリントは日中MWIRで致命的なため。熱漏洩ΔTはプロセス温度駆動で昼夜安定であり、夜間は背景ノイズが消えコントラストが改善する）。視線角を固定したタスキングで時系列比較可能性を担保 |
| 気象データ | 正規化 | メソ解析+協力プラント構内の簡易気象計で外気温・風速の交絡を除去。**降雨イベント後の温度回復の遅さ**（劣化保温材の指紋）は、現行1機体制では成立機会が年数回に限られるため機会的補助特徴量とし、9機化後に定常特徴量へ昇格させる。代替として撮像機会と整合する**季節湿潤指標**（乾燥期にも高熱損失が残る資産=内部滞留水の疑い）を採用 |
| 操業データ | 交絡分離 | 顧客提供の稼働カレンダー・ユニット別負荷。最小要件（粒度・頻度）を協力先選定条件として明記。提供が得られない場合も兄弟資産差分により負荷交絡を共通モード除去できる縮退設計を持つ |
| 高分解能光学（30cm級） | 確証+幾何基準 | 外装板の錆汁・変形・脱落の目視サイン検出による熱異常の確証。熱画像のサブピクセル位置合わせ基準（3.5m画素に対し位置ずれは境界画素で偽信号を生むため、資産マスクは境界1画素をエロージョン） |
| InSAR | 隣接用途 | タンク基礎の不等沈下監視（確立用途）を同一プラットフォームで併売 |
| 3D都市モデル（PLATEAU等）/プラント3Dモデル | 可視面計算・可視化 | 可視面カバレッジの事前計算、建物影・視線幾何の補正、管理者向け可視化。プラント内部詳細3Dは顧客所有物であり、PLATEAUは周辺市街地との統合可視化に用いる |
| 資産台帳・CMMS | ベースライン | 外装材質・経年（ε推定）、外装更新履歴（張替えによる見かけ温度急変=偽トレンドの除去）、補修履歴（検証の教師ラベル） |

### 2.5 システム出力
月次「設備熱健全性レポート」: 資産別異常スコア（シーン内相対値。熱損失・CO2換算は誤差幅併記の参考値）、要点検優先順位、ステップ変化アラート、可視面カバレッジ明示。年次「劣化トレンド評価」。CMMS連携APIを想定。

## 3. 新規性・競合比較

### 3.1 新規性の主張（限定を明示する）
本提案の新規性は「**衛星熱赤外を、保温システム劣化の保全業務（点検優先順位付け）に適用し、兄弟資産差分・操業データで交絡を分離する枠組み**」にある。2026年8月時点の調査（Web・学術検索・特許概観・衛星事業者の公開ユースケース確認。調査範囲は付録に開示）では、プラント・エネルギーインフラの保温システム劣化に特化した衛星監視サービスは商用・研究とも確認できなかった。

なお、近傍領域には以下の先行事例が**存在する**。これらは「衛星熱赤外で施設の熱を監視する」ことの実現性の証拠であると同時に、本提案が差分を明示すべき相手である:
| 先行事例 | 内容 | 本提案との差分 |
|---|---|---|
| SatVu Heat Loss Index（ESA資金、2025） | 建物ストックの熱損失指標化 | 対象は都市建物の省エネ評価。保全業務（点検派遣の意思決定）への組込み、低放射率金属外装への測定設計、操業交絡の分離を含まない |
| Fortum×Advian（2020、フィンランド） | 衛星データによる地域熱供給導管の漏水検知実証 | 埋設導管の漏水（舗装越しの熱異常）であり、露出資産の保温劣化とは物理・対象が異なる。かつ単発実証に留まる |
| 北欧の航空機TIRによる地域熱供給網サーベイ | 商用実績数十年 | 航空機による周期サーベイ。衛星による定常監視・多拠点横並びとは頻度・スケールが異なる |
| Saudi Aramco特許群 | 地上固定/移動熱画像×MLのCUI検知 | 地上センサ前提。業界が熱赤外の物理を信頼している証左でもある |

### 3.2 競合との位置関係
| 主体 | 内容 | 本提案との関係 |
|---|---|---|
| 手持ち/ドローン熱赤外点検 | cm級分解能・高精度だが範囲・頻度がコストに比例 | 分業: 衛星=本社・地区レベルのポートフォリオ監視と派遣先決定、ドローン・徒歩=拠点レベルの精密確認。ドローン点検事業者は競合でなく販売チャネル候補 |
| SatVu等の衛星事業者 | 熱データ供給。建物熱損失等のユースケース訴求あり | データ供給者。保全業務特化の解析層は空白。JSI経由の国内調達ルートあり |
| NTT（偏波SAR陥没予兆）・天地人・ASTERRA | 地中埋設管の劣化・漏水 | 対象資産・物理原理が異なり非競合 |

### 3.3 なぜ既存プレイヤーがやっていないか
100m級熱赤外では設備単位の解析が物理的に不可能だった。3.5m級は2023年のHotSat-1で技術実証されたが同機は運用停止に至り、**安定した商用供給は2026年6月のHotSat-2で初めて成立した**。観測資産の商用化から数週間の現時点で先行者が不在なのは「価値がない」ではなく「時間の問題」であり、先に測定設計の妥当性検証と顧客実績を積むことが参入優位になる。

## 4. 検証計画

コンテスト日程（1次審査結果10月下旬 → 開発・メンタリング約7カ月 → 2027年5月下旬開発完了 → 7月2次審査）に整合させ、**7カ月で証明すること／しないこと**を先に定義する。

- **証明すること**: (1) 測定設計（シーン内相対比較）の総合誤差バジェットが要求感度に届くこと、(2) 劣化既知/健全既知の資産を衛星指標が判別できること（横断判別）、(3) 業務プロトタイプが動くこと（2次審査要件「プロトタイプ以上」への対応）
- **証明しないこと（正直に開示）**: 月次時系列による漸進劣化トレンドの前向き実証（季節1周期以上を要するため、商用PoCフェーズの課題として設計書のみ提示）

### Phase 0: 応募〜1次審査（自費・公開データ）
- HotSat-2公開サンプル（横浜等）で国内プラント・エネルギー施設の描写力を確認
- JSI経由でNEdT実力値（公表は感度<2Kのみ）・夜間タスキング仕様・価格を照会
- 階層2のシグナル/ノイズ一桁概算と、降雨後特徴量の成立確率計算（降雨統計×晴天夜間率×パス頻度）を文書化

### Phase 1: 開発期間前半 — 誤差バジェット検証
- チェックポイント: **τ（大気透過）・ε（放射率）・天空反射・位置合わせ残差を含む総合誤差バジェット**が、シーン内コントラスト検知の要求（数℃）に届くか
- 協力プラント（または類似設備）での外装板MWIR放射率実測、晴天/曇天夜間の見かけ温度変動実測
- 実タスキング1〜2回で夜間・視線角固定撮像の運用性と実効取得率（雲統計）を確認

### Phase 2: 開発期間後半 — 横断判別検証（主実証）
- 協力先の補修履歴・直近点検記録から「劣化既知」「健全既知」の資産・区画を各30〜50抽出し、少数エポックの衛星指標（シーン内コントラスト・兄弟資産差分）による判別性能を**AUC・分離度**で定量化（時間でなく資産数でnを稼ぐ設計）
- 衛星撮像と同夜の手持ちサーモ地上同時観測を2〜3回実施し、衛星指標と地上実測の相関を直接示す
- 操業データが期間内に得られない場合の縮退検証（公開情報+気象正規化+兄弟差分のみ）を並走させ、操業データの寄与をアブレーションで評価
- ステップ変化検知は、期間中に発生した補修・外装更新イベントを「既知の段差」として検出デモ

### Phase 3: 業務実装デモ（2次審査ピッチ)
- 優先順位レポート+PLATEAU/3Dモデル可視化+CMMS連携のプロトタイプ（「プロトタイプ以上」要件への回答)
- 費用対効果試算（熱損失は相対値+誤差幅で提示）と、地区相乗りの商用単価シミュレーション

### 検証の生死を分けるチェックポイント（先に潰す順)
1. 総合誤差バジェット（ε・天空反射込み）がシーン内数℃コントラストに届くか（Phase 0〜1）
2. 横断判別のAUCが実用水準（目安0.7以上）を超えるか（Phase 2）
3. タスキング実勢価格で地区相乗り時の商用単価が成立するか（Phase 1で価格確認、Phase 3で試算）

## 5. 事業化パス

- **顧客と予算の入口**: プラントオーナー・エネルギー事業者の設備保全部門。本サービスは既存点検の置換ではなく**追加の上流工程（新規費目）であることを直視**し、稟議根拠を3本柱で設計する: (1) 高圧ガス保安法・認定事業者（スーパー認定）制度の高度モニタリング要件への適合——連続運転期間延長（定修間隔延伸）の経済価値を主根拠に、(2) 非計画停止・CUI起因事故リスクの低減、(3) 熱損失・CO2定量化（省エネ法定期報告・GX開示の補強材料。独立の財布ではなく稟議の添付資料と位置づける）
- **課金と原価構造**: 監視面積・資産数ベースの月額SaaS+初期アセスメント。タスキング原価は1シーンがコンビナート集積地区・臨海部の複数事業所を同時カバーする特性を活かした**地区相乗りモデル**（同一撮像の複数社販売、損益分岐は同一シーン3〜4社）で逓減させる。よって営業は個社単位でなく**地区単位**（コンビナート連携組織・保安協議会・地域熱供給協会経由）
- **ドローンとの分業**: 衛星が構造優位を持つのは (1) 多拠点ポートフォリオの横並び常時監視、(2) 地区相乗りによる面あたり単価、(3) 立入困難な第三者資産・休止設備、(4) 全拠点同一センサでの時系列一貫性。単一拠点の精密点検はドローンの土俵であり、ドローン点検事業者へは優先順位レポートを供給し共同提案する（チャネル化）
- **展開順序**: (1) 協力先1〜2社PoC（清掃工場・地域熱供給等の公共性の高い施設から。操業データのセキュリティ審査リードタイムを考慮し縮退検証を並走）→ (2) 高経年コンビナート1地区の相乗りパッケージ化（目標5〜8社）→ (3) 大手多拠点契約 → (4) 海外は雲量条件の良い乾季市場から選定。地域熱供給・自治体施設は収益柱ではなく「都市インフラ」実績とフレーミングの基盤と内部整理する
- **市場規模（正直な提示）**: 国内TAMは年20〜40億円規模のニッチ。同一データ資産からの隣接展開（タンク基礎InSAR、稼働・排熱インテリジェンス、GX開示支援）で顧客単価を引き上げ、コンテスト賞金はタスキング実費・検証費に充当した上で、NEDO他事業・事業会社との共同開発契約への接続を想定
- **感度不足時の縮退でも残る最小価値**: 加熱炉・高温配管系・大型タンク等の高ΔT資産に絞った監視は、燃料費削減だけで単独ROIが成立し得る（劣化保温100m²=年200〜300万円級の損失）

## 6. リスクと対応

| リスク | 内容 | 対応 |
|---|---|---|
| 測定感度 | 低放射率金属外装+天空反射で数℃信号が埋もれる | 設計転換済み（シーン内相対比較・兄弟差分）。Phase 0〜1で総合誤差バジェットを最初に検証。不足なら高ΔT資産に縮退（縮退後も単独ROIが立つことを5節に明示） |
| ε経年変化・外装更新 | 放射率変化が偽トレンドを生む | 外装更新履歴（CMMS）で時系列を区切る。兄弟差分で同調成分を相殺。中長期はLWIR帯コンステレーションとの2帯域併用でT/ε分離を目指す |
| テーマ適合性 | コンビナートが「都市インフラ」に含まれるか | 要項がテーマ1例示に「電力・ガス」「上水道」を明記しており、発電所・清掃工場・地域熱供給・上下水処理場は正面から適合。コンビナートは横展開先に配置。事務局照会を8/24期限までに実施（文案作成済み） |
| 過去テーマ重複 | 省エネ・GX前面化はGreen Earth重複と判定され得る | 主目的を「インフラ構造物の劣化の点検・監視」に固定。CO2は副次便益として記載。照会で確認 |
| データ供給 | HotSat-2一社一機依存。要項上、事務局のデータ購入は「確約なし」。3.5m級MWIRの代替衛星は現存しない | タスキング費は自己負担計画を持つ（賞金・自己資金の充当計画を応募書類に明記）。1機喪失時は提案自体が停止するリスクとして正直に開示し、constellr等LWIR系での部分縮退（大型資産限定）を予備線とする |
| 協力先確保 | 操業データ提供はセキュリティ審査で6〜12カ月かかり得る | 候補リスト作成済み（公共性の高い清掃工場・地域熱供給を優先）。操業データなしでも成立する縮退検証を主実証に設計済み。NEDOメンタリング・ネットワーキングは補助線 |
| 雲・撮像機会 | 光学系共通の制約 | ステップ検知・横断判別は単発欠測に頑健。夜間撮像併用。実効取得率をPhase 1で実測しKPI化 |
| 後発大手の参入 | SatVu垂直統合、計測・エンジ大手、商社系 | 堀は (1) 地区相乗りの原価優位（顧客密度の先取り）、(2) スーパー認定・保安当局文脈での審査実績、(3) 顧客点検記録で校正した資産別ベースラインモデルの契約上の設計。教師データ蓄積は「堀」ではなく立ち上げ速度の優位と正直に位置づける |
| データ権 | 点検記録・操業データの帰属は顧客側 | PoC契約時点で派生データ（匿名化特徴量・校正済みモデル）の利用権条項を設計 |
| ドローン自動化 | 単一拠点ではdrone-in-a-boxが価格・分解能で優位 | 商流を多拠点・地区相乗り・第三者資産に限定し、ドローン事業者をチャネル化（5節） |
