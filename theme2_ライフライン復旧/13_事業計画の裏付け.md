## 0. 一言でいうと、今どこが弱いか

**強い**: 顧客が実在し、その顧客が**この商品カテゴリを既に発注している**（那須岳）。予算行も特定できている。課題側は計画書の原文で裏が取れている。テーマ1の事業性レビューで【致命的】だった A-1（「点検予算は既存」という誤認＝実際には新規予算の獲得が要る）は、**本案では成立しない**——予算行の事業内容に本提案の作業が名指しされている。

**弱い**: 次の4つが同時に成り立っている。

1. **年間の市場フローが小さい**。計画の策定・改定は**年1〜3件**（8.4節の自前確認）。単価Pを掛けると市場全体で**年300万〜6,000万円**。21座の一巡総額（P=1,000万で2.1億円）は**在庫であって年商ではない**。
2. **堀が無い**。手法は公知、データは無償、参入コストは7人月。
3. **元請けになれない**。しかも2026年8月10日の制度確認（2節）で**再委託という逃げ道が中核部分では制度上ふさがっている**ことが分かった。「再委託による業務の実績は業務実績として認めない」と明記されており、**卸し続けても資格は育たない**。残るのは設計共同体（実績が付く）か売り切り（付かない）の2つ。
4. **開発期間の自己負担が賞金と同じ桁**。実施スケジュール全体で13人月＝1,300〜2,600万円（1位賞金2,000万円の0.65〜1.30倍）。しかも懸賞金は2027年9月末の一括精算払い。

**この4つを足すと、審査委員席の投資家・銀行から見た絵は「良い調査案件であって、事業ではない」になる。** 前回のテーマ3代表審査委員（SPACETIDE）の講評がそのまま刺さる:

> 「環境と防災というテーマはビジネスにするのがすごく難しいと思っています。**マネタイズは行政連携が伝統的なやり方だったんですが**、1位の企業も大学スタートアップを作っていくそうなので今後はぜひチャレンジをしていただきたい。**ビジネス自体が持続しなければ環境問題も解決しない**」

「行政連携＝伝統的なやり方」という言い方は、**行政受託だけのモデルは減点される**という審査委員側の本音である。本案は現状まさにそれなので、2・5・6節で正面から扱う。

**ただし、規模で戦わないと決めたなら、戦うべきは「この年数千万円が守っているものの大きさ」である**（→8節）。前回1位（ONS 波高マップ）は自社売上ではなく**顧客側で動く金額**（年間GHG 6.43億t削減・利益8.5兆円増）で1位を取った。

失うもの3つ:
1. **価格決定権**。単価は元請けとの交渉で決まる。
2. **顧客接点**。要件を握るのは元請け。
3. **実績の帰属**。プロポーザルの実績要件は元請けに積み上がる。**再委託を続けても元請けになる資格は育たない**——「場合がある」ではなく、ガイドラインが「再委託による業務の実績についても、業務実績として認めない」と明記している（G-5）。

**負う側も書いておく**（負債の自白が抜けていた）:
4. **責任だけが残る組み合わせ**。成果物は構造物の**設計外力**になるのに、価格決定権が無い。→7節の責任分界。

**本番で飛ぶ質問**（過去回 #12 の型）:

> 「技術を持っているなら、なぜ自分で元請けを取りに行かないのですか。コンサルに卸すだけなら、コンサルが同じものを内製した瞬間に終わりませんか」

**現状の答え**: 用意できていない。**最優先で埋めるべき穴。** ただし**前提の事実確認は済んだ**（下の「未解決Gが閉じた」）——「主たる部分の再委託」の制限に**掛かる読みが自然**であり、そうであれば残る選択肢は「共同提案（設計共同体）」か「成果物の売り切り」だけになる。上の質問に対しては、**「卸すのではなく設計共同体の構成員として入る。制度上そこにしか実績が付かないからだ」**という形で答えを組める。

選択肢（Gの結果で絞り込み済み。**決めるのはユーザー**）:
- (a) **一般競争参加資格の認定**を取る。→ **選択肢ではなく (c)(d) の前提**。数年かけて育てる話ではなく資格審査の申請で取れる（G-9）
- (b) **データプロダクトとして複数のコンサルに横売り**する（独占を求められないかの確認が必要）。→ **再委託の制限を受けない唯一の形。ただし実績はゼロのまま**（G-5）
- (c) **県事業（国費率1/2）側**を狙う。直轄より小規模だが元請けの座が空いている可能性がある。→ **県ごとの約款の確認が残る**
- (d) **パシフィックコンサルタンツとの共同提案**を第一候補にする（相手が実在する分、最も具体的）。→ **実績が自社に付く唯一の道**（G-6）。**障害は構成員にも実績を求める要件**（G-7）

→ **未解決A（意思決定）は残る。未解決G（再委託可否の事実確認）は閉じた。**

**2つ目は特に重い。** 5節の参入者候補に防災科研＋新潟大を挙げているが、公的研究機関は科研費・受託研究で成果を出し、**価格ゼロで**提供しうる。しかも8.5節は、同チームの令和6年度報告書に「**UAVの撮影機会を増やすとともに、衛星データの取得についても検討していく**」と書かれていることを記録している——**彼ら自身が衛星に向かっている**。8.8節の棲み分け（彼らは発災時リアルタイム×地上観測、本案は平時の年超過確率×衛星）は**技術の棲み分けであって、価格ゼロの供給者が同じ発注者に現れたときの答えではない**。

### 使える答えと、使えない答え

**使えない答え**（テーマ1のレビューで B-1【重大】として明示的に潰された型）:
- 「先行者利益」「知見の蓄積」「教師データの蓄積」——**いずれも堀ではない**

**使える可能性がある答え**（いずれも未検証）:

1. **較正データの排他性**。融雪係数の較正には火口高度の実測が要り、それは防災科研＋新潟大が蔵王で4冬期分持っているだけである。組めればアクセスが参入障壁になりうる。**ただし相手の意思次第で、独占契約が取れる保証はない。組めなかった場合の分岐まで決めておくこと**（→未解決D）。
2. **A案の資産がB案の原価を下げる構造**。A案で作る「その座の消雪日アーカイブ」は、同じ座の当年SWE（B案）の原価をそのまま下げる。これは唯一「A案がB案の堀になる」筋である。**ただし論拠に増分比14.3%（4.2節）を使ってはいけない**——あれは座間再利用比であって同一座のA案→B案の増分ではない（V-21。詳細は6節）。**現時点でこの筋は「計算で示せる」ではなく「計算すれば示せるかもしれない」である。** →6節。
3. **「確率分布を計画の設計値に翻訳する」能力**。8.7節の推奨。**能力の主張であって模倣を防ぐ仕組みではない。堀としては弱い**。
4. **規格化**。年超過確率分布の出し方（標本期間・外挿の方法・誤差の開示）を仕様書に載せる。**最も筋が良いが、経路が特定できていない。**
   - 火山砂防の技術指針類を書き、かつ検討業務の受注常連でもあるのが**STC**である。**同一組織が「最大の競合」と「唯一の規格化経路」を兼ねている。** 敵に回すのか組むのかは未解決A（元請けか再委託か）と同じ分岐点である。
   - 分解して決めるべき4点: (i) 対象（指針／マニュアル／標準仕様書のどれか）、(ii) 相手（国交省砂防部／STC）、(iii) 入口（共同研究／技術報告／学会発表）、(iv) 期限。

**現時点の誠実な結論: 堀は無い。** 本案が守られているのは「まだ誰もやっていない」からであって、構造的な障壁があるからではない。**この自白は隠すより出したほうが良い**——「では何で勝つのか」を先に語れる。

| フェーズ | 内容 | 収益の性格 |

| Phase 1（2027年度〜） | 計画改定・ハザードマップ見直しの**検討業務への技術提供** | **単発**。年1〜3件 |
| Phase 2（2028年度以降） | 「リアルタイムハザードマップの運用・整備の推進」に接続し、積雪火山21座へ**年次提供** | **継続**。ただし**仮説** |

### 名指しすべき閉ループ

8.7節は「**A案（年超過確率分布）を主、B案（当年SWE）を Phase 2 に置く。逆順は不可。B案は既に調達が始まっており、審査項目の『他社との優位性』に答えられなくなる**」と決めた。一方6節は「**リカーリングの器はB案側にある**（毎冬の値が要るから）」と書いている。

**並べると閉じたループになる:**

> **A案＝優位はあるが単発で年1〜3件。B案＝継続だが優位が無く、既に他社（パシフィックコンサルタンツ）が調達に入っている。**

**本番で飛ぶ質問**:

> 「Phase 2 で毎年入ってくるとおっしゃいましたが、**その毎年の部分は、優位性が無いとご自身で説明された商品ですよね。継続収益は誰が守るんですか。**」

Phase 2 について仮説なのは「発注が年次であるか」ではなく「**年次になったとき自社が勝てるか**」である。

### 抜け道は3つ。どれかに決める必要がある

- **(i) A案で入った座については当年SWEも継続契約に含める設計**。A案で作る消雪日アーカイブがその座のB案の原価を他社より下げる。**ただし「増分比14.3%」を根拠にしてはいけない**（V-21）——14.3%は `t2_unit_economics.py` の `additional_site_total / first_site_total = 1.0/7.0`、すなわち**A案を2座目以降に横展開したときの座間再利用比**であって、同一座のA案→B案の増分ではない。しかも**B案は融雪が終わる前の冬期に値が要る商品で、A案の成果物である消雪日アーカイブは融雪後にしか確定しない**。再利用できるのは処理基盤・AOI・渓流区分・雲雪判別のチューニング・融雪係数の較正結果であって、消雪日そのものではない。**「唯一、計算で示せる筋」と自称している唯一の筋が、まだ計算で示せていない。**（→ `t2_unit_economics.py` にA案保有時のB案の作業分解を足すのが次の宿題。出た値が小さければ堀の論拠、大きければ(i)を第一候補から降ろして(iii)に寄せる材料になる）
- (ii) B案は捨て、A案の対象を21座→50火山（火山災害警戒地域）へ広げる
- (iii) B案の勝ち筋を認め、那須岳を取った事業者と組む（→未解決A(d)）

**「年超過確率分布は毎年更新される」は答えにならない。** 43年の標本に1年足しても分布はほとんど動かないので、毎年買う理由にはならない。ここは誤魔化さないこと。

> 国の事業評価は確率規模別の被害額と生起確率から便益を出す。**本提案はその確率規模を積雪について与える。**

### 発注者にとっての便益は「減らす」でも「増やす」でもない

**本番で飛ぶ質問**:

> 「事業費を減らせるという提案を、**事業費で仕事をしている発注者が買いますか。**」

> 発注者が得るのは事業費の増減ではなく、**単一の外挿値では持てなかった説明根拠**である。「なぜこの規模なのか」を観測に基づいて説明できるようになる。
